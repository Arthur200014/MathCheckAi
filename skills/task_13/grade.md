# Skill: проверка задания ЕГЭ №13

Используй только вместе с `criteria/task_13.md` и `knowledge/EXPERT_RULES_13.md`.

## Цель

Классифицировать корректность решения и найденные ошибки без требования совпадения с эталонным способом. Итоговый балл 0–2 вычисляет deterministic rubric после Grader.

## Алгоритм

1. Проверь, присутствует ли содержательное решение пункта а). Если нет — кандидат на 0 баллов.
2. Восстанови математическую логику пункта а):
   - допустимость преобразований;
   - корректность простейших уравнений;
   - полноту полученного множества корней;
   - ОДЗ / ограничения, если они возникают.
3. Используй deterministic tools для тех утверждений, которые можно проверить точно.
4. Определи состояние пункта а): `correct`, `computation_error_only`, `substantive_error`, `uncertain`.
5. Отдельно проверь пункт б):
   - исходный отрезок / условие отбора;
   - каждый выбранный корень;
   - отсутствие лишних корней;
   - отсутствие потерянных корней;
   - если используется окружность — соответствие экспертным требованиям к рисунку.
6. Классифицируй каждую найденную ошибку (`computation_error`, `substantive_math_error`, `root_selection_error`, `diagram_selection_error`, `ambiguous`).
7. Передай статусы и класс ошибки deterministic rubric; сам итоговый балл не генерируй.
8. Если невозможно надёжно отличить вычислительную ошибку от содержательной — не угадывай; выставь `MANUAL_REVIEW_REQUIRED`.

## Запреты

- Не штрафовать за иной корректный метод.
- Не использовать «похожесть на эталон» как критерий.
- Не считать LLM-эталон абсолютным источником истины: учитывать результаты deterministic verifier.

## Отдельная проверка рисунка
Если ученик использует тригонометрическую/числовую окружность, правильный неупорядоченный список корней сам по себе не делает пункт б) верным. Нужно учитывать соответствие отмеченной точки её подписи/номеру и вычислению. Явная перестановка подписей точек, неверное положение подписанного угла или другой подтверждённый `DIAGRAM_INVALID` означает ошибку пункта б) (`diagram_selection_error`).
