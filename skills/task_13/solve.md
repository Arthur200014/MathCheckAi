# Skill: независимое решение задания ЕГЭ №13

Этот файл нужен Solver Agent для построения независимого эталона. Он НЕ задаёт критерии оценивания.

## Общие требования

1. Решить пункт а) полностью школьными методами.
2. Не подгонять решение под работу ученика.
3. Допускаются разные корректные способы преобразований.
4. Если выполняется деление на выражение, проверить потерю решений / случай нулевого делителя.
5. Получить полное множество решений и явно указать целочисленные параметры.
6. Пункт б) выполнять отдельно.
7. Для отбора по отрезку по умолчанию предпочитать точный алгебраический способ (двойные неравенства / перебор целых параметров), потому что он легче проверяется детерминированно.
8. Тригонометрическая окружность допустима как дополнительная визуализация, но не обязательна: экспертные материалы разрешают и другие корректные способы отбора.
9. Ответ записывать отдельно для а) и б).

## Machine-readable часть

Помимо текстового решения Solver должен вернуть данные для deterministic verifier:

- остаток исходного уравнения в синтаксисе SymPy (`lhs-rhs`);
- все найденные семейства общего решения в форме `a + b*n` или аналогичной SymPy-строки;
- границы отрезка пункта б);
- выбранные корни пункта б).

В machine-readable выражениях использовать `pi`, `sqrt`, `sin`, `cos`, `tan`, `log`, `exp`, `**`, а не LaTeX.
