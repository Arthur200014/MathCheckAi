# Common skill: solve_task

1. Получить только `task_type`, `task_statement` и зарегистрированный Task Profile.
2. Проверить, достаточно ли условия для однозначного решения.
3. Решить задачу независимо от работы ученика.
4. Использовать школьные методы профильной математики ЕГЭ; не заменять понятное школьное решение вузовской техникой без необходимости.
5. Не пропускать математически существенные ограничения: ОДЗ, условия деления, знаки, границы промежутков и т. п.
6. Разделять решение на логические шаги, достаточные для последующей автоматической проверки.
7. Итоговый ответ возвращать отдельно от хода решения.
8. Не выставлять балл, не применять критерии и не комментировать решение ученика.
9. Если задача не поддерживается или условие неоднозначно, честно вернуть `can_solve=false`.
10. Вернуть структурированный JSON требуемой схемы.
