# Проверки безопасности

Workflow `security` запускается при push в main, в ветку homework/security, при pull request и вручную.

Gitleaks проверяет историю Git на токены, ключи и пароли. Значения найденных секретов скрываются в логах. При обнаружении секрета проверка завершается ошибкой.

pip-audit проверяет зависимости из requirements.txt, включая транзитивные зависимости, по базе известных уязвимостей. В логе указываются пакет, версия, идентификатор уязвимости и версии с исправлениями. При обнаружении уязвимости проверка завершается ошибкой.

Результаты: [GitHub Actions](https://github.com/Arthur200014/MathCheckAi/actions/workflows/security.yml).

Отсутствие находок не гарантирует полную безопасность приложения. Проверка не заменяет анализ исходного кода и образов контейнеров.
