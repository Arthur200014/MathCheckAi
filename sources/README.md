# Источники task pack №13

`ЕГЭ_13_критерии_решения_сканы.pdf` — пользовательский материал обучения эксперта, содержащий:

- критерии 2/1/0;
- методические комментарии;
- эталонные решения;
- сканы ученических работ;
- экспертные баллы и комментарии.

В коде проекта содержание источника не подменяется знаниями модели. Для benchmark нельзя подавать модели целую страницу из раздела «Примеры оценивания»: на странице одновременно присутствуют условие, официальный ответ и экспертный балл. Сначала надо вырезать только область ученической рукописи.
